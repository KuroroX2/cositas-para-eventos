Infraestructura & Despliegue

Cómo Conectar NIC.cl, Vercel y Supabase

Pasos claros para que tu proyecto esté 100% en línea con dominio propio y base de datos.

1 Comprar Dominio en NIC Chile (nic.cl)

Entra a nic.cl y registra tu dominio (ej. cositasparaeventos.cl). No necesitas tener el servidor listo de inmediato: al comprarlo, déjalo con la opción por defecto. Más adelante, en la sección de Servidores DNS de NIC.cl, solo tendrás que ingresar los nombres de servidor que te dé Vercel (ej: ns1.vercel-dns.com y ns2.vercel-dns.com).

2 Conectar Repositorio de GitHub en Vercel

Crea una cuenta en vercel.com (puedes iniciar sesión con tu cuenta de GitHub). Haz clic en "Add New... Project", selecciona el repositorio donde están colaborando y presiona "Deploy". ¡Vercel compilará la web y te dará una URL inmediata con HTTPS gratuito!

# Comandos para subir cambios a GitHub: git add . git commit -m "Web Cositas para Eventos lista para Vercel" git push origin main

3 Configurar Base de Datos en Supabase

Crea un proyecto gratuito en supabase.com. Ve a la pestaña "SQL Editor" y pega el contenido del archivo supabase_schema.sql que preparamos en tu proyecto. Esto creará automáticamente las tablas para guardar las confirmaciones de asistencia (RSVP) y las fotos que suban los invitados en la Caza de Fotos.
