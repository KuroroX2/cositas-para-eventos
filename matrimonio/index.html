Cómo Vestir

Código de Vestimenta

Estilo: Elegante Campestre / Formal de Tarde. Queremos que luzcas increíble y te sientas muy cómodo.

Para Ellas

Vestidos Fluidos & Frescura

  • Vestidos largos o midi en telas livianas y frescas.
  • Se recomienda tacón ancho, cuñas o flats para caminar cómodamente en el pasto.
  • Reservar el color blanco y marfil exclusivamente para la novia.
Para Ellos

Traje Formal de Tarde

  • Traje de dos piezas en tonos azul, gris, beige o tierra.
  • Camisa formal; corbata o corbatín opcional para mayor frescura.
  • Zapatos de cuero o calzado formal cómodo para exteriores.
